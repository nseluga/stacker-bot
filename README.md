# stacker-bot

Reinforcement learning for Big Two under a set of home rules: a simulator for 3–8 players and
1–2 decks, a Deep Monte-Carlo specialist for 4 players / 1 deck, a test of belief-sampled search,
and a generalist across all six configs. Ships as a GitHub Pages dashboard and a preprint-shaped
writeup.

Status: scaffold only, no code yet. First milestone is the engine.
